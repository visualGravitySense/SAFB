## Рекомендации по UX/UI

### 1. Добавить «мягкий» CTA рядом с основным

Вместо одного «Broneeri Nüüd» добавить второй вариант с меньшим обязательством:

- **Küsi pakkumist** (Запросить предложение) — без ощущения немедленной брони
- **Võta ühendust** (Связаться) — ведёт к форме бронирования или контакту

Пример:

```
[Broneeri Nüüd]  [Küsi pakkumist]
```

### 2. Упростить путь к бронированию

- Сделать **одношаговую форму** (дата + email/телефон) как первый шаг
- Кнопку «Broneeri grupp» включать уже после заполнения этих полей
- Остальные поля (тип события, формат и т.п.) показывать на следующих шагах

### 3. Усилить видимость CTA

- **Sticky CTA** внизу экрана на мобильных: «Broneeri bänd» или «Küsi pakkumist»
- **Повторять CTA** после блока музыки и галереи
- В навигации выделить «Broneeri» визуально (цвет, иконка)

### 4. Использовать поведение пользователей

- После **Kuula Muusikat** показывать блок: «Broneeri bänd oma üritusele» с кнопкой
- В **Kontakt** добавить ссылку/кнопку «Broneeri bänd» и наоборот — в форме бронирования ссылку на контакт

### 5. Снизить психологический барьер

- Добавить текст рядом с CTA: «Tasuta konsultatsioon» (бесплатная консультация)
- Показать цену «Al. 990€» рядом с кнопкой, чтобы снизить неопределённость
- Добавить отзывы/цитаты рядом с формой бронирования

### 6. Улучшить трекинг

- Добавить `data-button-label="Broneeri Bänd"` на все кнопки бронирования
- Отдельно трекать клики по «Broneeri» в hero, в nav и в форме

### 7. Мобильная версия

- Убедиться, что CTA не перекрывается и хорошо заметен
- Проверить размер кнопок (минимум 44×44 px)
- Убедиться, что форма удобна на маленьких экранах

### 8. A/B-тесты текстов CTA

- «Broneeri nüüd» vs «Küsi pakkumist» vs «Võta ühendust»
- «Broneeri bänd» vs «Broneeri grupp»

## Приоритеты

| Приоритет | Действие | Ожидаемый эффект |
|-----------|----------|------------------|
| Высокий | Добавить «Küsi pakkumist» рядом с «Broneeri» | Больше кликов за счёт меньшего обязательства |
| Высокий | Sticky CTA на мобильных | CTA всегда доступен при скролле |
| Средний | Упростить форму (включить кнопку раньше) | Меньше отказов на этапе заполнения |
| Средний | CTA после музыки и галереи | Использование «горячего» интереса |
| Низкий | A/B-тесты текстов | Оптимизация конверсии |

Могу помочь с конкретными правками в коде (Hero, Booking, Navigation) по этим пунктам.
